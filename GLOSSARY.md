# rbika.com

Personal site: a Blog of Posts, a listing of Projects, plus a few static pages.

## Language

**Post**:
A published piece of writing.
_Avoid_: article, entry, piece

**Project**:
A software thing you built, listed on /projects. It has a name and a short description, and may have a GitHub URL and a website URL. A Project is not a Post. The same software can appear as a Project and as a tool on Uses.
_Avoid_: portfolio item, case study, repo, work

**Tag**:
A named classification a Post may carry, identified by a slug and shown as a label. Only defined Tags may be attached to a Post. A Post carries many Tags; a Tag appears on many Posts.
_Avoid_: category, topic, keyword

**Blog**:
The listing of Posts, newest first. It may be constrained to Posts that carry one Tag.
_Avoid_: feed, index, archive
